# Chrome DevTools MCP isolation evidence
URL: https://developer.chrome.com/blog/chrome-devtools-mcp-debug-your-browser-session
Accessed: 2026-07-14
Product/version: Chrome M144 feature article, published 2025-12-11 and updated 2025-12-16

> Run Chrome with a Chrome DevTools MCP server-specific user profile (current default).

> Run multiple Chrome instances in isolation with each instance running in a temporary profile.

> Every time the Chrome DevTools MCP server requests a remote debugging session, Chrome will show a dialog to the user and ask for their permission.
