How the ranking works — in one idea

A good question to research is one the field can’t agree on yet — and that we hold the data to settle. So instead of ranking topics by how popular they are, we rank them by disagreement. For each topic we gather independent measurements of the same number — at the same redshift and galaxy mass, so it’s apples-to-apples — and simply ask: do they agree?

What the score is built from

The ranking isn’t one mysterious number — it’s disagreement, kept honest by two guards. Multiply the three; miss any one and the topic drops out.

Getting this honest took five passes, each removing one way to be fooled: counting words → mistaking popularity for disagreement → mistaking cosmic evolution for a fight → mistaking the mass sequence for one → and finally mining stellar masses from full-text tables to test gas metallicity properly. That last pass deflated a false signal and found a real one: an early-universe (z>7) metallicity disagreement, right where JWST is looking.
