Trust layerClaim-level view

The big idea: claims should carry their evidence.

A page is not just prose. It is a set of claims. Each claim should be connected to papers, votes, disagreements, and a visible trust label.

Paper

The actual source material: arXiv papers, DOI papers, or other references. This is the ground truth we want visible.

Claim

A specific sentence or idea in the wiki. Example: “environment affects galaxy quenching.” Claims are small enough to judge.

Evidence

A paper can support, weaken, contradict, or only loosely relate to a claim. We need both support and counter-pressure.

Trust badge

A simple reader-facing label: consensus, accepted, debated, challenged, or unverified. It is a signpost, not a final verdict.

Why this matters

If we only generate better prose, readers still cannot tell which sentences are solid and which are disputed. If we expose the evidence map, readers and operators can see where the system is confident, where it is uncertain, and where human review matters.
