How to calibrate

  1. Read the base claim and the evidence sentence side by side.
  2. Use the assistant recommendation only as a hint, not as authority.
  3. Pick exactly one Human final decision. If unsure, choose unsure and write why.
  4. Optionally add source-family/dedupe and threshold notes where they matter.
  5. Export filled CSV/JSON and return it for post-label readiness analysis. Do not use this page as write approval.

Rubric quick reference

Count as support

The evidence directly supports the base claim and can count as a pro/supporting row after dedupe.

Count as weakening

The evidence directly contradicts or materially weakens the base claim. High-risk if it touches consensus.

Nuance only

The evidence is relevant but mainly limits, qualifies, or refines the wording; do not count as a clean vote.

Drop no effect

The evidence is unrelated, too generic, duplicate-only, metadata noise, or below useful threshold.

Route as new claim

The evidence is useful astronomy content, but it belongs under a different/new claim rather than this base claim.

Needs rerun / unsure

Use for ambiguous, low-context, or threshold-sensitive cases. Human uncertainty should block writes, not force a guess.
