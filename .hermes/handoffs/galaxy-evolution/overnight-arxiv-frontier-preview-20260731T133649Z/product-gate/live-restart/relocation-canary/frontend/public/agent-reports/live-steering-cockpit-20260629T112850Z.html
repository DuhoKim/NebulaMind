What changed, in plain words

Before: the live Galaxy page could look source-empty because two helper tables were empty. After this local fix: the page can fall back to the claim/evidence records that already prove which papers support the page.

  • /citations still uses page_citation_links first. If that is empty, it reads existing claim/evidence rows.
  • /fact-sources still uses fact_sources first, then inline hero_facts[].source, then existing claim/evidence rows.
  • The fallback only reads existing data. It does not backfill, promote, edit, or mutate anything.

What did not happen

  • No production database writes.
  • No claims created.
  • No coverage_ready or promotion flags changed.
  • No arxiv_papers.related_pages mutation.
  • No backend/API deploy or backend/API restart for this code, so nebulamind.net does not reflect the source-surface fix yet. The frontend report service was refreshed only so this cockpit and timestamped report files would serve publicly.
