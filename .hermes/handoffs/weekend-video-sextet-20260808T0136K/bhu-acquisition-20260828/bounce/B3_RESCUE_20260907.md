## 1. Constraint propagation before integration

Let S=sigma^2. The exact cosmic-time system obtained from B2's directional field equations is

```

H_dot = kappa epsilon/3 - 3 H^2
S_dot = -6 H S
n_dot = beta H^4 - 3 H n
epsilon_dot = -4 H epsilon + 2 alpha n beta H^4
T_dot = [-4 H F(T) + 2 alpha n beta H^4]/F'(T)
C = 3 H^2 - kappa(epsilon-alpha n^2) - S.
```

Epsilon and T are alternative coordinates for one evolution equation. In (b), `T_dot=-HT+alpha n beta H^4/(2T^3)`. In (c), use the explicitly specified F and F'. Neither retains the paper's temperature equation (37), which depended on the discarded n=h_n T^3 closure.

`C_dot+6HC=-kappa[epsilon_dot+4H epsilon-2alpha n beta H^4]=0`.

The first-law residual `epsilon_dot-2alpha n n_dot+3H(4epsilon/3-2alpha n^2)` also vanishes. The script substitutes each F and symbolically computes both residuals. **CONSTRAINT_RESIDUAL_b=0; CONSTRAINT_RESIDUAL_c=0.** Both checks finish before any numerical integration; a nonzero residual stops the program.

For numerical conditioning use d tau=dt/a^3 and the invertible coordinates

`x=-ln a, u=-H a^3, N=n a^3, E=epsilon a^6, S0=S a^6`.


Prime denotes tau derivative. **C_tau'=0 identically**, without projection. The script verifies this identity and the caloric chain rule `F'(T)T'=exp(6x)[4uE+2alpha N N']` for both closures. ## 2. Scaling before numerics, including the energy source

**Closure (b):** number balance gives exactly

`N(t)=n0+integral_0^t a^3 Psi dt`,
`alpha n^2=alpha a^-6 N(t)^2`,
`S=S0 a^-6`.

During collapse with n>0 and beta>0,

`d ln(alpha n^2)/d ln a=-6+2beta H^3/n<-6`.

For S>0, `d(alpha n^2/S)/dt=2alpha n Psi/S>0`. The integral also covers n0=0; the logarithmic formula is used only for n>0. Number density **grows faster** than a^-3 in collapse. “Falls slower” would confuse expansion with collapse.

**Closure (c):** the same integral, scaling and inequalities hold, because its caloric relation changes neither number balance nor isotropic shear evolution. Its temperature equation differs as specified above. Thus **TORSION_SCALING_b=HELPS** and **TORSION_SCALING_c=HELPS**. This is an instantaneous exponent plus an exact integral, not a constant modified power-law ansatz.

The helpful torsion/shear direction holds for any nonnegative production, independently of H^4. But it does not alone prove a bounce: first-law heating gives `d(epsilon a^4)/dt=2alpha n Psi a^4>=0`.

To settle the competition analytically, take x as independent variable while H<0, and set

`Q=3H^2 a^6=kappa E+S0-kappa alpha N^2>0`.

Then

```
N_x = beta (Q/3)^(3/2) exp(6x)
E_x = -2E + 2alpha N N_x
Q_x = -2kappa E < 0.
```

The source contributions to Q_x cancel **exactly through the first law**, rather than by neglecting heating. E>=E0 exp(-2x)>0.

**Finite-bounce proof for every alpha>0 and fixed beta>0, both closures.** Let N_star=sqrt(S0/(kappa alpha)). Suppose collapse continues with N<=N_star. Then `kappa E=Q-S0+kappa alpha N^2<=Q`, so Q_x>=-2Q and Q>=Q0 exp(-2x). Therefore

`N_x>=beta (Q0/3)^(3/2) exp(3x)`.

This has an unbounded integral: N must exceed N_star at finite x unless a bounce intervenes. A root itself requires N>N_star since E>0. Initial equality crosses immediately under the strictly positive source; this includes S0=N0=0.

After N1>N_star at finite x1, define D=kappa alpha N1^2-S0>0. Monotonic N gives `Q_x=-2(Q+kappa alpha N^2-S0)<=-2D`, hence a root occurs no later than x1+Q(x1)/(2D). There is no prior finite-x blow-up: Q<=Q0 bounds N_x on finite-x intervals, and the constraint bounds E. At the root, Q_x=-2kappa E_b<0, so `dt/dx=a^3sqrt(3/Q)` is integrable. All variables are finite, and `H_dot_b=kappa epsilon_b/3>0`. The smooth proper-time system crosses H=0 at a genuine minimum. Finite shear and finite proper time also keep the directional scale factors regular there.

**Prescription dependence is load-bearing.** The exponential lower bound uses fixed positive beta and exactly Psi=beta H^4 throughout contraction. An arbitrary nonnegative source could create too few particles to reach N_star. Universal rescue is therefore a result of this prescription, the retained p=epsilon/3 EOS and effective first law, not production per se. Psi vanishing at H=0 does not erase previously accumulated N. The proof is not uniform as beta->0 or alpha->0; alpha=0 is excluded.
