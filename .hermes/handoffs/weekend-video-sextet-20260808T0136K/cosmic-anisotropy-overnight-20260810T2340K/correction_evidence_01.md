## Description

Dataset, mask and code associated with

https://inspirehep.net/literature/1820376

(https://arxiv.org/abs/2009.14826)

Code and README for selecting the sample from CatWISE can be found in Generatecode.tar.gz

Code and README for masking the sample, evaluating the dipole, as well as the Monte Carlos for statistical significances can be found in Resultscode.tar.gz

(This github repository: https://github.com/rameez3333/CatWISEdipole )

Note that the final result is for the sample with W1 less than 16.4 cut applied, whereas this file includes objects with W1 less than 16.5.

Additional code required to produce the catalog from scratch is available in " [secrest+21\_extra.tar.gz](https://zenodo.org/api/files/6cb5d4a5-505a-4703-9351-958666e847f2/secrest%2B21_extra.tar.gz)"
