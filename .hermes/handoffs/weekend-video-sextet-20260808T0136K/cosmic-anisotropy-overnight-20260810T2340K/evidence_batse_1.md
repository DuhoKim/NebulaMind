The Fourth BATSE Gamma Ray Burst Catalog
contains a set of tables that characterize the gamma-ray bursts that have been
detected with BATSE. This catalog covers bursts detected up to and
including **29 August 1996**. The following tables comprise
the 4B Catalog:

| Table Name | Description |
| :-- | :-: |
| [Basic](https://gammaray.msfc.nasa.gov/batse/grb/catalog/4b/4br_basic.html) | The BATSE trigger number, burst name, time of trigger, derived source <br> direction, angle from geocenter to burst direction,<br> information about burst overwrites for each burst. This table contains <br> 1637 triggers. |
| [Flux and Fluence](https://gammaray.msfc.nasa.gov/batse/grb/catalog/4b/4br_flux.html) | Includes BATSE trigger number, peak flux on the 64 ms, 256 ms, and <br> 1.024 s trigger timescales, and fluences in four<br> energy channels for each burst. This table contains 1292 triggers. |
| [CMAX/CMIN](https://gammaray.msfc.nasa.gov/batse/grb/catalog/4b/4br_cmax_cmin.html) | The table gives the BATSE trigger number, cmax/cmin and cmin values for <br> the 64 ms, 256 ms and 1.024 s trigger<br> timescales for each burst. This table contains 912 triggers. |
| [Duration](https://gammaray.msfc.nasa.gov/batse/grb/catalog/4b/4br_duration.html) | The table gives the BATSE trigger number, and the durations required <br> for integration of 50% and 90% of the burst fluence<br> for each burst. This table contains 1234 triggers. |
| [Comments](https://gammaray.msfc.nasa.gov/batse/grb/catalog/4b/4br_comments.html) | Includes BATSE trigger number and free form comments for each burst. |
| [Exposure](https://gammaray.msfc.nasa.gov/batse/grb/catalog/4b/4br_exposure.html) | The sky exposure as a function of declination is given for the 4B <br> Catalog and several subsets. |
| [Trigger Efficiency](https://gammaray.msfc.nasa.gov/batse/grb/catalog/4b/4br_efficiency.html) | Describes the fraction of time a burst will be triggered on each of <br> the trigger timescales as a function of GRB intensity. |
| [Trigger Criteria](https://gammaray.msfc.nasa.gov/batse/grb/catalog/4b/4br_trigger_criteria.html) | Trigger threshold and energy range vs. time. |
