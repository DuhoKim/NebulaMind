# DESI Data Releases [¶](https://data.desi.lbl.gov/doc/releases/\#desi-data-releases "Permanent link")

## Spectroscopic Data Releases [¶](https://data.desi.lbl.gov/doc/releases/\#spectroscopic-data-releases "Permanent link")

### [Data Release 1 (DR1)](https://data.desi.lbl.gov/doc/releases/dr1/) — March 19, 2025 [¶](https://data.desi.lbl.gov/doc/releases/\#data-release-1-dr1-march-19-2025 "Permanent link")

**Data**: [https://data.desi.lbl.gov/public/dr1](https://data.desi.lbl.gov/public/dr1)

**Paper**: [DESI Collaboration _et al._ (2026)](https://ui.adsabs.harvard.edu/abs/2026AJ....171..285D/abstract), _Data Release 1 of the Dark Energy Spectroscopic Instrument_

**Overview**: [DR1 Documentation](https://data.desi.lbl.gov/doc/releases/dr1/)

Data Release 1 (DR1) is the first release of DESI
[Main Survey](https://data.desi.lbl.gov/doc/glossary/#main-survey) data, including
18.7 million new spectra observed from May 2021 through June 2022.
It also includes a reprocessing of
[Survey Validation](https://data.desi.lbl.gov/doc/glossary/#survey-validation)
data previously released
with [EDR](https://data.desi.lbl.gov/doc/releases/edr/) using the latest algorithms and calibrations.

### [Early Data Release (EDR)](https://data.desi.lbl.gov/doc/releases/edr/) — June 13, 2023 [¶](https://data.desi.lbl.gov/doc/releases/\#early-data-release-edr-june-13-2023 "Permanent link")

**Data**: [https://data.desi.lbl.gov/public/edr](https://data.desi.lbl.gov/public/edr)

**Paper**: [DESI Collaboration _et al._ (2024)](https://ui.adsabs.harvard.edu/abs/2024AJ....168...58D/abstract),
_The Early Data Release of the Dark Energy Spectroscopic Instrument_

**Overview**: [EDR Documentation](https://data.desi.lbl.gov/doc/releases/edr/)

The DESI Early Data Release includes spectra for 1.8 million unique targets from [Survey Validation](https://data.desi.lbl.gov/doc/glossary/#survey-validation) observations taken from December 2020 through June 2021, as well as a few [commissioning](https://data.desi.lbl.gov/doc/glossary/#commissioning) and [special](https://data.desi.lbl.gov/doc/glossary/#special-survey) tiles observered during the same time period. [Read more…](https://data.desi.lbl.gov/doc/releases/edr/)

## Targeting Data Releases [¶](https://data.desi.lbl.gov/doc/releases/\#targeting-data-releases "Permanent link")

### Early Target Selection (ETS) [¶](https://data.desi.lbl.gov/doc/releases/\#early-target-selection-ets "Permanent link")

**Data URL**: [https://data.desi.lbl.gov/public/ets](https://data.desi.lbl.gov/public/ets)

The Early Target Selection (ETS) release includes the output of [desitarget](https://desitarget.readthedocs.io/en/latest) algorithms applied to [DESI Legacy Imaging Surveys DR9](https://www.legacysurvey.org/dr9/) photometry to select the targets observed for DESI Survey Validation and Main Survey observations.

## Other DESI Data [¶](https://data.desi.lbl.gov/doc/releases/\#other-desi-data "Permanent link")

### Education and Public Outreach (EPO) [¶](https://data.desi.lbl.gov/doc/releases/\#education-and-public-outreach-epo "Permanent link")

**Data URL**: [https://data.desi.lbl.gov/public/epo](https://data.desi.lbl.gov/public/epo)

Example DESI data and visualizations used for Education and Public Outreach (EPO).

- [DESI-HighSchool](https://data.desi.lbl.gov/public/epo/DESI-HighSchool):
datasets used by the [DESI High: School of the Dark Universe](https://github.com/michaelJwilson/desihigh)
outreach program
- [desi3d](https://data.desi.lbl.gov/public/epo/desi3d): interactive 3D visualization of DESI data obtained in 5 hours of observing
- [desifp](https://data.desi.lbl.gov/public/epo/desifp/): (UPCOMING) description of the DESI focal plane for a general audience

### Transients [¶](https://data.desi.lbl.gov/doc/releases/\#transients "Permanent link")

**Data URL**: [https://data.desi.lbl.gov/public/transients](https://data.desi.lbl.gov/public/transients)

Ad-hoc releases of (meta)data for DESI observations of transients. This directory is largely deprecated in favor of posting to [Zenodo](https://zenodo.org/communities/desi-pub), but it could have future datasets that are larger than viable for Zenodo.

### Data Supporting Published Papers [¶](https://data.desi.lbl.gov/doc/releases/\#data-supporting-published-papers "Permanent link")

**Data URL**: [https://data.desi.lbl.gov/public/papers](https://data.desi.lbl.gov/public/papers)

**Zenodo**: [https://zenodo.org/communities/desi-pub](https://zenodo.org/communities/desi-pub)

**Value Added Catalogs**: [VAC documentation page](https://data.desi.lbl.gov/doc/vac/)

Supporting data for individual published papers are available via [Zenodo](https://zenodo.org/communities/desi-pub) or [https://data.desi.lbl.gov/public/papers](https://data.desi.lbl.gov/public/papers) when the supporting dataset is
too large for Zenodo:

- [cosmosim/nbody\_code\_comparison2021](https://data.desi.lbl.gov/public/papers/cosmosim/nbody_code_comparison2021/): supporting files for [Grove _et al._ (2022)](https://ui.adsabs.harvard.edu/abs/2022MNRAS.515.1854G/abstract):
_The DESI N-body Simulation Project I: Testing the Robustness of Simulations for the DESI Dark Time Survey_
- [DR2 cosmology chains and posterior maximization results](https://data.desi.lbl.gov/public/papers/y3/bao-cosmo-params/README.html): supporting files for [DESI Collaboration _et al._ (2025)](https://ui.adsabs.harvard.edu/abs/2025PhRvD.112h3515A/abstract), _DESI DR2 results. II. Measurements of baryon acoustic oscillations and cosmological constraints_

Papers may also release their supporting data as a [Value Added Catalog](https://data.desi.lbl.gov/doc/vac/) accompanying a data release.
