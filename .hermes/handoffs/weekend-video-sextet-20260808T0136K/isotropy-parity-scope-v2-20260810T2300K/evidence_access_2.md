## Notes on User Registration

You need to register for a user account if you wish to search/request/retrieve the data.  The use of the HSC data archive is restricted to non-commercial, scientific/educational purposes.  The registration information will be used only for the operation, maintenance and development of the HSC data archive system. We occasionally send notices about system maintenance and new releases to all the registered users.

## Client Tools

We offer a few command-line tools to retrieve data from our server as well as some useful off-line tools.

[Command-line SQL Tool](https://hsc-gitlab.mtk.nao.ac.jp/ssp-software/data-access-tools/tree/master/pdr3/hscReleaseQuery "")

This tool allows you to send a query and retrieve data from your terminal.  This will be useful for sequential data retrieval.

[Server-side Cross-match Tool](https://hsc-gitlab.mtk.nao.ac.jp/ssp-software/data-access-tools/tree/master/pdr3/hscSspCrossMatch "")

We currently do not offer an environment in which users can upload their catalogs and match with the PDR3 database tables, but this tool allows you to do essentially the same job.

[Postage Stamps in Color](https://hsc-gitlab.mtk.nao.ac.jp/ssp-software/data-access-tools/tree/master/pdr3/colorPostage "")

If you want postage-stamps of your objects in color, you can upload an object list with this tool.

[Image Stitcher #1](https://hsc-gitlab.mtk.nao.ac.jp/ssp-software/data-access-tools/tree/master/pdr3/imageStitcher1 "")

A patch is a 4k x 4k image.  It is relatively large, but one may wish to generate a larger image.  This tool stitches adjacent patches in the same tract together.

[Image Stitcher #2](https://hsc-gitlab.mtk.nao.ac.jp/ssp-software/data-access-tools/tree/master/pdr3/imageStitcher2 "")

Similar to Image Stitcher #1, but this one allows you to stitch patches in different tracts together.  The HSC (or LSST) pipeline has to be installed to use this tool.  The overlapping regions between the adjacent tracts are not exactly the same; tract A may have slightly different DNs and astrometry from tract B in the overlapping region.  This tool simply adopts the pixels from tract B in the resultant image.  This tool can also be used for CCD images to visualize a full focal plane image from a visit.

[Mask Viewer](https://hsc-gitlab.mtk.nao.ac.jp/ssp-software/data-access-tools/tree/master/pdr3/maskViewer "")

Coadd images have a mask layer, which carries useful information about object footprint, various pixel masks, etc.  This tool overlays a specific mask bit on a coadd image using ds9.

[Image cutout (command-line)](https://hsc-gitlab.mtk.nao.ac.jp/ssp-software/data-access-tools/-/tree/master/pdr3/downloadCutout/ "")

A command-line tool to download image cutouts.  It can also be used as a module and can be called form your code.

[PSFpicker (command-line)](https://hsc-gitlab.mtk.nao.ac.jp/ssp-software/data-access-tools/-/tree/master/pdr3/downloadPsf/ "")

A command-line tool to download model PSF images.  It can also be used as a module and can be called form your code.

## Ancillary Data Products

Some of the ancillary data products such as a collection of public spectroscopic redshifts are available from the database, but some are provided as fits files.  Links to these fits files can be found in [the Available Data page](https://hsc-release.mtk.nao.ac.jp/doc/index.php/available-data__pdr3/).
