# A1 two-stage freeze — DRAFT replacement clause, 2026-09-07

UNADOPTED AUTHOR DRAFT. This is proposed binding text, not evidence that either freeze occurred.

**Two separate mandatory events.** INPUT FREEZE and WINNER FREEZE are distinct records at different times. A reference to “freeze” must identify which event it means. A later winner record never modifies the earlier input record.

**(i) INPUT FREEZE, C, before naming any seed round.** After Duho adopts the final A1, and before a drand round is designated, fix the adopted procedure digest, complete fixed family/grid (all 96 configurations and enumeration), tuning objective/floors/tie-break, selection and all run code, preprocessing, environment, the eligible/exclusion/derived-failed input files and source CSV, and every other pre-existing input actually read. Resolve every INPUT-manifest path and digest, including the eligible-file length. No choice in C may depend on tuning, holdout or validation results. C also fixes the schemas, source-selection and deterministic production rules, access gates and integrity checks for files necessarily generated later; it contains no pretend digest for a future winner, draw, beacon response or result.

Anchor C's manifest digest, adopted procedure digest and commit ID using A1's minimal mechanism: a public-remote push whose server-side timestamp is recorded by a third party, or a provider-timestamped chat statement of the digest by someone other than the lane owner. Retain the mechanism, external reference and third-party UTC A. Only AFTER this anchor may the first default-mainnet round scheduled at least A + 600 seconds be named: r = 1 + ceil((A + 600 - G)/P), T = G + (r - 1)P, G = 1595431050, P = 30. Record designation after publication and before T; missing the deadline is a recorded abort, not a replacement round. The published digest is the authority for all checks against C. This event needs no seed or drawn-list digest: those values do not exist yet and must never be fabricated to satisfy a record template.

After the named round is authenticated under A1, derive the split using C's exact inputs/code. Retain, push and anchor the draw record with seed/round, C reference, three selection-input hashes, selector hash and drawn-list hashes before any development fetch or label access. Future data-read inventories are stage records under C's already fixed production rules; they cannot alter the population, split, procedure, grid or code. Run the complete fixed tuning search on the tuning set only, retaining all configuration and per-object results.

**(ii) WINNER FREEZE, W, after tuning and before holdout opens.** Once all prescribed tuning evaluations finish, apply the fixed eligibility, objective and tie-break to determine the sole winner; no eligible winner closes option A. Serialize the winning configuration and config_id, hash the actual file and retain it in W. W binds C's externally anchored digest/reference; the seed/round and drawn-list digests; the complete tuning results and every tuning-evidence file read to select the winner; the winner configuration file; and the identical family, grid, selection/scoring code, preprocessing and environment hashes already fixed at C. W adds the winner and completed evidence, not new code or tunable choices. The winner cannot be pre-declared at INPUT FREEZE because it is the result of the prescribed comparison of all eligible configurations on tuning data not yet drawn or evaluated.

Publish and externally anchor W before the first participant, process or service accesses any holdout pixel, tensor, label or per-object outcome (catalogue IDs alone are not opening). W's digest and file pins may be included in the already required holdout-opening attempt record, avoiding an extra publication mechanism: that record must identify W and C, carry seed/round, three selection-input hashes, selector hash and drawn-list hashes, and be pushed AND anchored under A1's attempt rule before access. Retain commit ID, mechanism, external reference and third-party UTC. The opening must post-date that evidence; partial access or a crash consumes the sole opening.

Evaluate only W's configuration once on holdout under the unchanged scientific gates. A holdout PASS confirms the already frozen identity; it is not permission to choose a new winner or alter C/W. Only after PASS and the retained V15 custody/fetch/lift conditions may fresh-validation pixels be fetched or opened as applicable. All validation uses the same W. A changed C/W binding, early access, retuning, replacement winner or repeated holdout invalidates and stops the run. Abort and attempt records remain required; no stage transition grants another attempt.

**Required order:** adoption → INPUT FREEZE and external anchor C/A → prospective round designation → authenticated seed → anchored deterministic draw → tuning → WINNER FREEZE and externally anchored W/holdout-opening record → sole holdout opening/evaluation → PASS and retained custody gates → sole fresh validation. Neither freeze can substitute for the other. Draw sizes, scored floors and denominator rules are not amended by this clause.
