# BS-1 RELEASE CHOICE — the Sep-5 brief (DR11 vs DR10.1), in plain words

**Prepared 2026-08-30 21:37 KST for the 2026-09-05 rule date. For Duho. One page.**

## The question, in one sentence

Which imaging data release feeds the successor study — the newest one (**DR11**) or the one
every measurement is already pinned to (**DR10.1**)?

## The good news first: you already decided this, by rule

When you authorized the successor draft on Aug 25, the fork was **bound inside the frozen
text as a rule, not an open decision** (§2.1). The rule, verbatim in effect:

- BS-1 resolves on the **earlier** of (i) the day DR11's photo-z product is confirmed
  publicly available, or (ii) **2026-09-05**.
- Pick **DR11 (Branch A)** only if its photo-z exists at that moment.
- Otherwise **DR10.1 (Branch B) selects automatically and the question closes**. Waiting
  longer would need a gated amendment.

So on Sep 5 there is **nothing for you to do** unless you want to override the rule.

## Status, measured tonight (2026-08-30, legacysurvey.org/dr11/files)

DR11 exists and ships sweeps, tractor catalogs, coadds, survey-bricks, randoms and masks —
**and no photo-z product of any kind**. Same state as at drafting (Aug 24). Photo-z is the
binding piece because the sample selection cuts on redshift (`0 ≤ z_phot < 0.15`); without
the product, the selection chain cannot run on DR11 at all.

## What each path means

**DR10.1 — where the rule is heading.** The pinned branch. Every measured pin stands — the
DR10-south universe, the count table, the selection, the parent, the 12,117-brick closure —
zero re-measurement, the preregistration proceeds exactly as written and refereed.

**DR11 — only if photo-z appears within six days.** The draft is honest about the price:
Branch A **voids the §0 pin and carries over none of the measured artifacts** — universe,
count table, selection, parent and closure all re-measured on DR11, re-pinned,
re-fixtured, plus a fresh text gate before freeze. The draft's own words: *"a new
preregistration in everything but name."* Realistically weeks, plus a new referee cycle
over the re-measured layer.

**Waiting past Sep 5** — a gated amendment. Only worth discussing if a DR11 photo-z release
is imminently announced and you affirmatively want the newer release at Branch A's full
price.

## My recommendation

**Let the rule fire: DR10.1.** The branch-invariance requirement already guarantees the
same code path either way, so DR11 stays fully available to a *future* study without
contaminating this one. Nothing scientific is lost that this preregistration ever claimed —
it was pinned to DR10 south from its first line.
