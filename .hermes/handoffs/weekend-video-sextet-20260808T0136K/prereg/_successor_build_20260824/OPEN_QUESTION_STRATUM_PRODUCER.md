## The options

**A. A new row — "Committee runner".** Reads cutouts (and/or Row D's instrument receipts) via Row B,
runs the two committee architectures, computes the |χ| tertiles, writes one canonical **χ-bearing
stratum-assignment artifact** into the main sealed store. Phase P2–P3, after Row D, before BS-2f.

**C. Derive it at Row F from existing artifacts.** Viable **only if committee outputs already exist
somewhere** — and they do not: no receipt class carries them. **C collapses into A or B** and is
listed so it is visibly closed, not silently available.
