## Numbered findings

### 1. BLOCKER — row C2 can see and export an outcome channel; the same capability has been moved earlier and renamed

**Row / sentence at issue.** Scope lines 29–35, 41–59; row C2 line 94; Part 3 C1 line 198; Part 4 D1 line 207; Part 5 item 1 line 216.

**Why it fails.** The construction rests on the implication “pre-inference + never invokes the classifier ⇒ outcome-free.” That implication is false on the draft's own definitions. Every cutout is χ-bearing (lines 29–35), because the image is the object from which handedness is inferred. C2 reads those bytes. The projection then carries their expected/actual checksums, while the default rule says an opaque digest of χ-bearing bytes is χ-bearing when the preimage schema is not on the closed list or permitted surface (lines 54–59). The cutout itself is on neither. Listing the projection in item (v) does not alter its preimage; it creates an internal exception that contradicts the digest rule and exposes the same verification oracle that the R4 report rejected.

The channel is wider than the checksums. C2 authors attempt identity, shape, and completion/non-finite status per object. The row does not derive attempt identity from a separately pinned immutable pre-inference manifest, does not make shape/status mechanically recomputable by an independent verifier, and does not authenticate the projection against such proofs. A C2 implementation that reads pixels can encode a derived sign in a permitted identifier, status choice, checksum selection, missing projection, or other permitted value. A pinned code digest makes one implementation inspectable; it does not by itself constrain what information a pixel-reading process can compute or what values it can write. The sentence “Never invokes the classifier” and the void condition “executing the classifier” also prohibit only one named implementation. They do not prevent equivalent handedness logic, a lookup, dynamic code, or a model under another symbol. No receipt, hermetic capability profile, semantic verifier, or adversarial producer fixture is required to fail if that happens.

This is therefore the characteristic defect named in D1: the writer moved from D to a pixel-reading process, but the outcome capability and writable channels remain. R5 has renamed rather than repaired the R4 finding.

**Smallest sufficient repair.** Keep all cutout digests inside the mediated sealed boundary. Pin one narrowly specified integrity transaction that derives each admissible predicate from a separately pinned pre-inference parent/attempt witness and the stored bytes, and export only authenticated predicate results whose values a separately pinned verifier recomputes. The exported schema must have no cutout digest, free-form identifier, caller-authored status, omission channel, or field whose legal values are not mechanically fixed. Require complete exact-parent closure before D may start. The BS-2a gate must inspect the real implementation and fixtures, reject ambient classifier/model/filesystem/network/dynamic-code capability, and reject adversarial implementations that encode a synthetic sign through every writable or missingness channel. If that construction cannot be demonstrated, do not call the projection non-χ-bearing or outcome-free.

### 2. BLOCKER — C2 cannot produce instrument execution/non-finite evidence before the instrument runs, and C2 → D is not an enforceable order

Thus the table allows the prerequisite objects for D to exist while C2 has not completed. Logging an out-of-order D touch does not prevent it.

Require C2 to close an authenticated exact-parent cutout-integrity manifest and stage-completion receipt before D is authorized. If no pre-lock non-outcome construction for reason (c) exists, defer or refuse that reason too; C2 cannot report a future execution state.

### 4. BLOCKER — the post-unblinding confidence cut is not bound to the mask, calibration, and power chain it changes

**Row / sentence at issue.** Phase line 72–76; rows F, I, J, and P lines 97–107; clause 3(b) lines 139–148; Part 2 item 5 line 189; Part 3 C2 line 199; current V15 §2.7(2), (5), and (7), lines 306–345; current §7 BS-2a and BS-3 rows lines 606 and 613.

**Why it fails.** The threshold is not wholly post-hoc: current V15 and BS-3 do pin τ before image access, and the YUI appendix defines the current rule as `|χ_net| > τ`. But R5 never binds row P to that exact field/function, threshold receipt, and comparison rule; it says only “applies confidence-based exclusion threshold.” Current §7 simultaneously assigns numeric-threshold authority to BS-2a, the slot all three seats refused. The proposed conforming edits do not resolve that ownership conflict.

More importantly, row P applies the cut after BS-2f has fixed the accepted mask, row F has assigned calibration bins, row I has produced calibration aggregates, row J has run Stage C on the BS-2f mask, and BS-L has signed the accepted-mask and calibration digests. A post-unblinding exclusion therefore changes the analysis population after the lock and after confirmatory power was evaluated. R5 acknowledges only that the run may be wasted if the sample becomes too small. It gives no deterministic halt rule, no final-mask binding, no calibration/allocation consequence, and no rule preventing the verdict from proceeding on a population for which BS-5f did not pass. The deferral loses more than convenience: it bypasses the locked decision-input chain.

**Smallest sufficient repair.** Before unblinding, pin one exact confidence field/function, numeric threshold, comparison rule, and authority in one slot only. Define the post-unblinding operation as a deterministic audited rule with no human choice. If it removes any object, require a precommitted consequence that preserves the preregistration—at minimum, recompute the final mask digest, calibration applicability, and Stage-C power under a pinned post-unblinding protocol and refuse the scientific verdict unless every locked adequacy condition still holds. Do not represent the pre-cut BS-2f mask as the mask bound to the verdict. If outcome-dependent post-unblinding selection cannot be reconciled with the primary estimand and calibration design, remove the cut rather than defer it.
