Uchuu DR2 Galaxy Catalogues
The galaxy catalogues are created using different methods, see below.
How to download the data
Uchuu:
Uchuu-nu2GC galaxy and AGN catalogues
for all 50 redshift snapshots. Main directory contains a README with details. Total data set is 17TB.
Uchuu-SDSS galaxy catalogues
for 32 Uchuu-SDSS lightcones, Uchuu-SDSS boxes (at z=0, 0.093, 0.19, 0.3), 5100 GLAM-SDSSbao lightcones and the SDSS data. Each directory contains a README with details. Total data set is 0.4TB.
The Uchuu-UniverseMachine galaxy catalogues
across the redshift range from z=0-7. Main directory contains a README with details. Total data set is 4.2TB.
WARNING(*)
The UCHUU-GLAM BOSS and eBOSS LRG lightcones: exploring clustering and covariance errors
.
Main directory contains a comments.tex file with details. Total data set is 1.6 TB.
(*)
The GLAM BOSS and eBOSS mock files in our public Skies & Universes repository are currently undergoing sanity checks after public users reported several issues: slight discrepancies in subsampling for completeness, corrupted files, strange artefacts where some catalogs appear incomplete, removal of galaxies due to redshift errors or fiber collisions, and consecutive realizations not being completely independent. While we believe most of these issues have been resolved, we are continuing with sanity checks to address some remaining concerns/issues. We apologise for any inconvenience caused.
