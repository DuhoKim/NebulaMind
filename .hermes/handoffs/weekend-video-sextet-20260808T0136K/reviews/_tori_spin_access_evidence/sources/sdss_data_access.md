# Data Access for SDSS DR17 Overview

> This page explains how to access DR17 data, and provides links to various data access tools.

The SDSS web sites offer several different online data access tools, each suited to a particular need. These sites are described in more detail in the [Available Tools](https://www.sdss4.org/dr17/data_access/tools/) page.

The information on this page is organized by type of data. Each section includes a table that describes a common task you might perform with that type of data, along with a link to the best tool for that task.

If your question isn't addressed here, please look at the [Frequently Asked Questions](https://www.sdss4.org/dr17/help/faq/) and/or [Tutorials](https://www.sdss4.org/dr17/tutorials/) help pages.

If you are having difficulty connecting to any data server, please check the [status page](https://www.sdss4.org/dr17/data_access/status/) for announcements about planned outages.

Data Release 17 includes these types of data:

- [Optical spectra](https://www.sdss4.org/dr17/spectro) of galaxies, stars and quasars from the SDSS extended Baryon Oscillation Spectroscopic Survey [(eBOSS)](https://www.sdss4.org/surveys/eboss/) and prior optical spectroscopic programs.
- [Infrared spectra](https://www.sdss4.org/dr17/irspec/) from the SDSS Apache Point Observatory Galaxy Evolution Experiment ( [APOGEE](https://www.sdss4.org/surveys/apogee/) and [APOGEE-2](https://www.sdss4.org/surveys/apogee-2/)), including stellar abundance estimates for additional elements from the [ASPCAP](https://www.sdss4.org/dr17/irspec/aspcap/) pipeline.
- Data cubes and maps from [integral field unit (IFU) spectroscopic observations](https://www.sdss4.org/dr17/manga/) of nearby galaxies from the SDSS Mapping Nearby Galaxies at APO ( [MaNGA](https://www.sdss4.org/surveys/manga/)) survey
- Spectra of the MaNGA [Stellar Library](https://www.sdss4.org/dr17/mastar) program ( [MaStar](https://www.sdss4.org/surveys/mastar/))
- Legacy [imaging](https://www.sdss4.org/dr17/imaging/) from prior SDSS programs
- A large selection of [Value Added Catalogs (VACs)](https://www.sdss4.org/dr17/data_access/value-added-catalogs/) from current and previous surveys

## How to find...

### Images

The SDSS has taken deep images of more than one-third of the entire night sky. You can view SDSS images online for any object or sky position in the survey area, and download images of SDSS fields as FITS files.

**I need to...****Tool to use**browse through sky images[Navigate](https://skyserver.sdss.org/public/VisualTools/navi/)create a telescope finding chart[Finding chart](https://skyserver.sdss.org/public/VisualTools/explore/chartinfo/)search-view-download SDSS imaging fields[Imaging Field Search](https://dr12.sdss.org/imaging/field/search)generate SDSS imaging mosaics[Imaging Mosaics](https://dr12.sdss.org/imaging/mosaics)get a list of thumbnails[Image List](https://skyserver.sdss.org/public/VisualTools/list/)

Since some stars were targeted for APOGEE infrared spectroscopy using 2MASS survey data, we also offer access to 2MASS images through the [Navigate](https://skyserver.sdss.org/public/VisualTools/navi/) tool (click on the 2MASS button).

Data from the SDSS-II Supernova Survey is not available in DR8-17, but is available in its entirety at the [SDSS-II Supernova Survey website](https://classic.sdss.org/supernova/aboutsupernova.html).

### Optical Spectra

Data Release 16 marks the final release of all [eBOSS](https://www.sdss4.org/surveys/eboss/) spectra, and includes all optical spectra from the original SDSS-I/-II, SEGUE, and BOSS, as well as additional optical spectra measured as part of the [Sloan Extended Quasar, ELG, and LRG Survey (SEQUELS)](https://www.sdss4.org/dr17/algorithms/ancillary/boss/sequels/) program. These spectra are all included into DR17. Seven eFEDS plates, observed in spring 2020, are published in DR17 for the first time.

### APOGEE and APOGEE-2 Spectra

DR17 is the final data release for APOGEE-2. DR17 also includes all previously released [APOGEE](https://www.sdss4.org/surveys/apogee/) and [APOGEE-2](https://www.sdss4.org/surveys/apogee-2/) spectra, which have been re-reduced with the latest version of the APOGEE data reduction and analysis pipeline.

### MaNGA Spectra

Data Release 17 is latest and final installment of the SDSS's [Mapping Nearby Galaxies at APO (MaNGA)](https://www.sdss4.org/surveys/manga) survey. It includes summary data on MaNGA targets and raw data consisting of data cubes. It also includes for the first time analysed data products and maps, as well as a visualisation and analysis tool (Marvin). These data products are all included in DR17.

### MaStar Stellar Library Spectra

Data Release 17 is the latest and final public data release for MaNGA's stellar library program [MaStar](https://www.sdss4.org/surveys/mastar/). It includes summary data on MaStar targets as well as single and combined optical spectra for stars. These data products are also included in DR17.

### Catalog Data

Catalog data summarize quantities measured from the images and spectra such as magnitudes, redshifts, and object classifications. These are available either from the Catalog Archive Server (CAS) database, or as binary tables in FITS file format.
